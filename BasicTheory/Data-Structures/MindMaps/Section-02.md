# 第二章思维导图

## 一、线性表的定义与基本操作（逻辑结构 & 运算）

### 1. 逻辑结构定义
- **定义**：相同数据类型的数据元素的 **有限序列**（$L = (a_1, a_2, ..., a_n)$）
- **重要术语**：
  - **表长/空表**（$n=0$）
  - **位序**：从 **1** 开始计数（与数组下标0区分）
  - **表头/表尾**（$a_1$ / $a_n$）
  - **前驱/后继**（除首尾外，一一对应）

### 2. 基本操作（数据运算）
- **核心操作（创销增删改查）**：
  - `InitList(&L)`：初始化
  - `DestroyList(&L)`：销毁
  - `ListInsert(&L, i, e)`：插入
  - `ListDelete(&L, i, &e)`：删除（e带回删除值）
  - `LocateElem(L, e)`：按值查找
  - `GetElem(L, i)`：按位查找
- **辅助操作**：`Length`（求长）、`PrintList`（打印）、`Empty`（判空）
- **关键考点（引用 &）**：
  - 凡是 **需要修改线性表 L** 或 **需要将值带回来（如删除的e）**，参数必须加 `&`（C++语法）。
  - 只读操作（如按值查找）无需加 `&`。

## 二、物理结构（存储结构）

### 1. 顺序存储（顺序表）
- **实现方式**：
  - **静态分配**：定长数组（`MaxSize`固定，不可变）。
  - **动态分配**：指针 + `malloc`（扩容时需复制数据到新区域，时间复杂度$O(n)$）。
- **核心特点**：
  - **随机访问**：通过下标直接定位，时间复杂度 **$O(1)$**。
  - **存储密度高**（只存数据，不存指针）。
  - **插入/删除不便**：需移动大量元素（平均移动表长的一半）。
- **基本操作复杂度**：
  - **插入/删除**：最好 $O(1)$（表尾），最坏/平均 $O(n)$（表头）。
  - **按位查找**：$O(1)$。
  - **按值查找**：$O(n)$（无序）；若有序，可用折半查找优化至 $O(\log n)$。

### 2. 链式存储（链表）

#### （1）单链表
- **节点定义**：数据域 `data` + 指针域 `next`。
- **两种实现**：
  - **带头节点**（推荐）：头节点不存数据，操作统一（无需特殊处理首元）。
  - **不带头节点**：头指针直接指向首元节点，表头操作需特殊处理。
- **核心操作（带头节点）**：
  - **按位插入/删除**：需遍历找到第 $i-1$ 个节点（前驱），时间复杂度 $O(n)$。
  - **指定节点后插**（`InsertNextNode`）：$O(1)$ 修改指针。
  - **指定节点前插**（骚操作）：插入到后继节点，交换数据域，实现“偷天换日”，$O(1)$。
  - **删除指定节点**：若为尾节点需遍历找前驱；非尾节点可复制后继数据再删除后继（“偷梁换柱”）。
- **建表方法**：
  - **尾插法**：设尾指针 `r`，每次在尾部插入，保持输入顺序（正序）。
  - **头插法**：每次在头节点后插入，输入顺序与链表顺序相反（**逆序**），常用于链表原地逆置。
- **查找**：只能顺序遍历，按位/按值查找均为 $O(n)$。

#### （2）双链表
- **节点定义**：`prior`（前驱） + `data` + `next`（后继）。
- **优势**：支持双向遍历，找前驱的时间复杂度为 $O(1)$。
- **插入/删除（核心易错点）**：
  - **插入**（在 $p$ 后插入 $s$）：需同时修改 $s$ 的 `prior`/`next` 和 $p$ 及 $p$ 后继的指针（若 $p$ 有后继）。
  - **删除**（删除 $p$ 的后继 $q$）：需修改 $p$ 的 `next` 和 $q$ 后继的 `prior`（若 $q$ 有后继）。
  - **口诀**：务必先处理好待插入/删除节点的“前后关系”，防止断链。

#### （3）循环链表
- **循环单链表**：尾节点 `next` 指向 **头节点**。
- **循环双链表**：
  - 头节点 `prior` 指向 **尾节点**，尾节点 `next` 指向 **头节点**。
  - **最大优势**：插入/删除时 **无需再判断节点是否为NULL**（因为环闭合，`p->next` 永远不为空）。
- **判空与判尾**：
  - 判空：`L->next == L`。
  - 判尾：`p->next == L`。
  - 遍历结束条件：`p != L`（回到头节点则结束）。

#### （4）静态链表（数组模拟）
- **定义**：用数组存储节点，节点内用 **游标（数组下标）** 代替指针。
- **约定标记**：
  - 头节点通常为 `a[0]`。
  - 游标为 **-1** 表示链尾。
  - 游标为 **-2** 表示该节点为空闲节点（未使用）。
- **特点**：
  - 插入/删除只需修改游标，无需移动数据。
  - 容量固定（数组定长），不支持随机访问（仍需遍历）。
  - **经典应用**：操作系统中的 FAT（文件分配表）。

## 三、顺序表 vs. 链表（全方位对比）

### 1. 存储分配
- **顺序表**：需 **大片连续空间**（容易产生碎片）。
- **链表**：离散分配，空间利用率高，扩容方便。

### 2. 存取方式
- **顺序表**：**随机存取**（$O(1)$）。
- **链表**：**顺序存取**（$O(n)$）。

### 3. 插入与删除
- **顺序表**：需移动约 $n/2$ 个元素（数据量越大，代价越高）。
- **链表**：只需修改指针（**已知位置时 $O(1)$**）。
- **结论**：链表更适合频繁增删的场景。

### 4. 查找操作
- **按位查找**：顺序表完胜（$O(1)$ vs $O(n)$）。
- **按值查找**（无序）：均为 $O(n)$。
- **按值查找**（有序）：顺序表可用折半查找（$O(\log n)$），链表仍为 $O(n)$。

### 5. 存储密度
- **顺序表**：密度 ≈ 1（无额外开销）。
- **链表**：密度 < 1（需额外存储指针）。

### 6. 选择依据（考研答题框架）
- **使用顺序表**：表长稳定、已知且不常变；以 **查询（尤其是按位查找）** 为主。
- **使用链表**：表长难以估计、频繁增删；无需随机访问。

## 四、本章核心易错点速记

1. **位序与下标**：位序从 1 开始，数组下标从 0 开始（`第i个元素` = `data[i-1]`）。
2. **引用 &**：凡是需要 **修改实参** 或 **带回返回值** 的必须加 `&`。
3. **链表指针修改顺序**：插入时 **先连后（s->next = p->next），再接前（p->next = s）**，防断链。
4. **头插法逆序**：输入 `1,2,3`，链表结果为 `3,2,1`，可用于链表逆置。
5. **循环链表判空**：头节点指向自身（`L->next = L`），而非 `NULL`。
6. **静态链表标记**：`-1` 表尾，`-2` 空闲。
