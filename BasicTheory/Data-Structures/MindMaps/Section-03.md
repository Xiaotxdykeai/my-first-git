# 第三章思维导图

## 一、栈（Stack）

### 1. 基本概念
- **定义**：操作受限的线性表，插入/删除只能在栈顶进行
- **特性**：后进先出（LIFO，Last In First Out）
- **术语**：栈顶（Top）、栈底（Bottom）、空栈
- **生活类比**：摞盘子、浏览器后退按钮、烤串

### 2. 基本操作
- **创**：`InitStack(&S)` —— 初始化
- **销**：`DestroyStack(&S)` —— 销毁（释放内存）
- **增（入栈）** ：`Push(&S, x)` —— 只能在栈顶操作
- **删（出栈）** ：`Pop(&S, &x)` —— 删除栈顶元素并用 x 带回
- **查（读栈顶）** ：`GetTop(S, &x)` —— 只读不删
- **判空**：`StackEmpty(S)`

### 3. 顺序栈
- **存储结构**：静态数组 + 栈顶指针 top（数组下标）
- **两种设计方式（必须统一，不能混用）** ：

| | top 指向栈顶元素（王道默认） | top 指向栈顶元素下一个位置 |
|---|---|---|
| 初始 top | **-1** | **0** |
| 判空 | `top == -1` | `top == 0` |
| 判满 | `top == MaxSize-1` | `top == MaxSize` |
| 入栈写法 | `data[++top] = x` | `data[top++] = x` |
| 出栈写法 | `x = data[top--]` | `x = data[--top]` |

- **时间复杂度**：所有操作均为 **O(1)**

### 4. 共享栈
- **结构**：两个栈共享同一数组，相向生长
  - 0号栈：从低端向高端增长（top0 初始 -1）
  - 1号栈：从高端向低端增长（top1 初始 MaxSize）
- **判满**：`top0 + 1 == top1`

### 5. 链栈
- **本质**：操作受限的单链表（只能在表头插入/删除）
- **推荐**：**不带头结点**（代码更简洁）
- **优点**：不会满（除非内存耗尽），适合容量不确定的场景
- **时间复杂度**：入栈/出栈均为 **O(1)**


## 二、队列（Queue）

### 1. 基本概念
- **定义**：操作受限的线性表，队尾插入、队头删除
- **特性**：先进先出（FIFO，First In First Out）
- **术语**：队头（Front）、队尾（Rear）、空队列
- **生活类比**：食堂排队、打印机任务队列

### 2. 基本操作
- **创**：`InitQueue(&Q)`
- **销**：`DestroyQueue(&Q)`
- **增（入队）** ：`EnQueue(&Q, x)` —— 只能在队尾
- **删（出队）** ：`DeQueue(&Q, &x)` —— 只能在队头
- **查（读队头）** ：`GetHead(Q, &x)` —— 只读不删
- **判空**：`QueueEmpty(Q)`

### 3. 队列的顺序实现（循环队列）
- **核心思想**：利用取模运算 `% MaxSize` 实现逻辑上的环形存储，解决“假溢出”
- **默认语义**：front 指向队头元素，rear 指向队尾元素的**下一个位置**

| 操作 | 代码 |
|------|------|
| 入队 | `Q.data[Q.rear] = x; Q.rear = (Q.rear+1)%MaxSize;` |
| 出队 | `x = Q.data[Q.front]; Q.front = (Q.front+1)%MaxSize;` |
| 队长 | `(Q.rear - Q.front + MaxSize) % MaxSize` |

- **判空/判满的三种方案**：

| 方案 | 判空 | 判满 |
|------|------|------|
| ① 牺牲一个存储单元 | `front == rear` | `(rear+1)%M == front` |
| ② 增设 size 变量 | `size == 0` | `size == MaxSize` |
| ③ 增设 tag 变量 | `front==rear && tag==0` | `front==rear && tag==1` |

> 王道默认使用**方案①**，考试时注意 rear 的语义（指向队尾元素还是队尾元素的下一个位置）

### 4. 队列的链式实现（链队列）
- **本质**：操作受限的单链表（队尾插入、队头删除）
- **必须同时保存 front 和 rear 指针**，确保入队/出队均为 O(1)
- **推荐**：**带头结点**（边界处理更统一）
- **链队列不会满**（无需判满）
- **关键边界**：带头结点时，删除最后一个元素后需将 `rear` 指向头结点

### 5. 双端队列
- **定义**：两端均可插入/删除的队列，是栈和队列的**泛化**
- **变种**：
  - **输入受限**：只能一端插入，两端均可删除
  - **输出受限**：两端均可插入，只能一端删除
- **核心考点**：输出序列合法性判断
  - 栈中合法的序列，在双端队列中**必定合法**
  - 判断原则：大元素先输出时，所有小元素必然已输入完毕，分析其相对次序能否通过两端操作实现
- **卡特兰数**：n 个元素入栈的合法出栈序列数为 $\frac{1}{n+1}\binom{2n}{n}$


## 三、栈的应用

### 1. 括号匹配
- **核心思路**：扫描括号串，左括号入栈，右括号弹出栈顶匹配
- **匹配失败三种情况**：
  1. 右括号单身（扫描到右括号但栈空）
  2. 左右括号类型不匹配
  3. 左括号单身（扫描结束栈非空）
- **为什么用栈**：越往后出现的左括号越先被匹配 → LIFO

### 2. 表达式求值

**三种表达式**：

| 类型 | 定义 | 是否需要括号 |
|------|------|-------------|
| 中缀 | 运算符在中间 | 必须 |
| 后缀（逆波兰） | 运算符在后面 | 无需 |
| 前缀（波兰） | 运算符在前面 | 无需 |

**中缀 ↔ 后缀/前缀转换原则**：

| | 后缀 | 前缀 |
|---|---|---|
| 转换原则 | **左优先**（左边的先算） | **右优先**（右边的先算） |
| 组合规则 | `左 右 op` | `op 左 右` |
| 求值扫描方向 | 从左到右 | 从右到左 |
| 弹操作数顺序 | 先弹右操作数 | 先弹左操作数 |

**用栈实现中缀转后缀（关键规则）** ：
- 操作数 → 直接输出
- 左括号 `(` → 直接入栈
- 右括号 `)` → 弹出栈顶运算符直到遇到 `(`
- 运算符 → **弹出栈中优先级 ≥ 当前运算符**的所有运算符，再入栈
  - `≥` 体现了**左优先原则**

**双栈法直接计算中缀表达式**：
- 操作数栈 + 运算符栈
- 遇到运算符时，弹出栈内优先级更高的运算符并立即计算

### 3. 递归
- **本质**：函数调用自身，背后依靠**函数调用栈**实现
- **每层栈帧保存**：返回地址 + 实参 + 局部变量
- **空间复杂度** = 递归深度 × 每层空间，通常为 **O(n)**
- **递归的两个要素**：① 递归表达式 ② 边界条件（缺一不可）
- **优缺点**：
  - 优点：代码简洁，适合树形结构问题
  - 缺点：可能栈溢出、空间开销大、存在重复计算
- **尾递归**：递归调用是函数体最后一条语句，某些编译器可优化为 O(1) 空间


## 四、队列的应用

| 应用场景 | 所属领域 | 为什么用队列 |
|----------|---------|-------------|
| 树的层次遍历 | 数据结构 | 先访问的节点，其子节点也先入队 |
| 图的广度优先搜索（BFS） | 数据结构 | 先访问的节点，其邻接点也先入队 |
| 就绪队列（CPU调度） | 操作系统 | 先来的进程先获得 CPU（FIFO） |
| 打印机缓冲区 | 操作系统 | 先提交的打印任务先打印 |


## 五、特殊矩阵的压缩存储

### 1. 数组的存储结构

- **一维数组**：`LOC(i) = LOC(0) + i × L`（下标从0开始）
- **二维数组**：
  - 行优先：`LOC(i,j) = LOC(0,0) + (i×N + j) × L`
  - 列优先：`LOC(i,j) = LOC(0,0) + (j×M + i) × L`

### 2. 特殊矩阵

| 矩阵类型 | 压缩策略 | 存储元素数 | 随机存取 |
|----------|---------|-----------|---------|
| **对称矩阵** | 只存主对角线+下三角（或上三角） | `n(n+1)/2` | 支持 |
| **下三角矩阵** | 下三角+主对角线 + 1个常量 | `n(n+1)/2 + 1` | 支持 |
| **上三角矩阵** | 上三角+主对角线 + 1个常量 | `n(n+1)/2 + 1` | 支持 |
| **三对角矩阵** | 只存三条对角线 | `3n-2` | 支持 |
| **稀疏矩阵** | 三元组表 / 十字链表 | 取决于非零元个数 | 三元组**不支持** |

**核心公式（行优先，对称/三角矩阵，下标从0开始）** ：

- 对称矩阵（下三角存储）：`k = i(i+1)/2 + j`（`i ≥ j`）
- 三对角矩阵：`k = 2i + j`（`|i-j| ≤ 1`）

**易错点**：矩阵下标从1开始还是从0开始、行优先还是列优先、数组下标从0开始还是从1开始，务必看清题目条件再套公式。


## 六、栈 vs 队列 对比总览

| 对比项 | 栈 | 队列 |
|--------|-----|------|
| 操作端 | 仅一端（栈顶） | 两端（队头+队尾） |
| 核心特性 | 后进先出（LIFO） | 先进先出（FIFO） |
| 插入位置 | 栈顶 | 队尾 |
| 删除位置 | 栈顶 | 队头 |
| 生活类比 | 摞盘子、浏览器后退 | 食堂排队、打印机 |


## 七、复杂度速查表

| 操作 | 顺序栈 | 链栈 | 循环队列 | 链队列 |
|------|--------|------|---------|--------|
| 入栈/入队 | O(1) | O(1) | O(1) | O(1) |
| 出栈/出队 | O(1) | O(1) | O(1) | O(1) |
| 读栈顶/队头 | O(1) | O(1) | O(1) | O(1) |
| 判空 | O(1) | O(1) | O(1) | O(1) |
| 判满 | O(1) | 不需要 | O(1) | 不需要 |
